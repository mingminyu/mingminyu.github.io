# 指标监控

> :iconfont-lark: https://haiercash.feishu.cn/wiki/QZxrwOXiRiq7MvkPgARceYCsnOf?table=tbli8gbL87t7TkT3&view=vewHzQgyan

在自研AI催收机器人上线后，构建一套全面的监控指标体系是保障业务效果的重要基石，一方面它能够直观地反映自研与厂商AI之间的回收差异；另一方面，借助多维度的漏斗拆解，帮助业务快速洞察转化流失点，驱动催收策略与AI模型的敏捷迭代。

本篇文章以 S0 阶段（逾期1-3天）为例，从**分案指标**、**流程链路**、**结果指标**、**过程指标** 四个方面，全面解析如何搭建一套可落地、可追踪的AI催收机器人的监控指标体系，为模型迭代与优化提供核心抓手。

## 1. 分案指标

- 统计指标：`案件量`、`案件占比`、`逾期金额`
- 维度指标：`周期Vintage`、`周期MTD`、`每日`、`每周`、`金额段`、`逾期标签`、`C卡BIN`
