## 1. 核身阶段

核身作为整个电催流程的第一步，主要目的是确认被催收对象是否为用户本人（监管要求），如果在未确认通话对象为用户本人的情况下便开始催收，容易引起用户投诉举报（投诉内容一般为泄露用户隐私）。

接下来，我们拆解下核身流程不同场景的应对话术：

```mermaid

    IDCheck21["二轮核身（质疑反问）"]
    IDCheck22["二轮核身（听不清/信号不好）"]
```

## 2. 逾期催收

核身通过后，一般会进入逾期催收环节，如果仅使用通用性催收话术，很难保证能有较好的回收效果，所以如何根据**用户的状态以及历史信息**构建**千人千面的差异化话术**，这里面有着大量的工作和难题需要去解决。

### 2.1 基于历史逾期标签

基于用户的历史逾期情况，可将客群划分为以下五类：

1. **从未逾期**（30天回收率 75%）：历史从未逾期过；
2. **惯性短逾**（30天回收率 90%）：近半年最大逾期天数 <= 7 且逾期次数 >= 2；
3. **轻度逾期**（30天回收率 80%）：近半年最大逾期天数 <= 7 且逾期次数 < 2；
4. **中度逾期**（30天回收率 70%）：近半年最大逾期天数 ∈ `(7, 15]`；
5. **重度逾期**（30天回收率 60%）：近半年最大逾期天数 > 15；

这些标签能反映出逾期用户的还款意愿强弱，使用针对性的话术能让 AI 更拟人，使得催收具备更强的交互性。
