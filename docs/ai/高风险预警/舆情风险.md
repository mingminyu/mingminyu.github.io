# 舆情风险

## 1. 业务背景

本文再介绍一个催收业务下比较常见的高风险场景——舆情风险，具体表现为“用户是否提及去抖音等社交平台上发表不利于公司品牌的言论“行为，类似的行为还有去法院起诉、报警等。通过模型准确识别出此类风险，提前进行易诉处置，避免升级成重大投诉。

## 2. 风险关键词

常见的风险关键词有：报警、起诉、曝光、维权、抖音、小红书、贴吧、法院、派出所、警察局、公安局等，但这些关键词在该场景中的表征能力并不强，导致简单的规则命中的准确率较低，例如：

- **报警**：用户表示让公司去报警解决，而非自己去报警投诉公司。例如，”你报警抓我好了”、“你去报警吧”、“你要不报警”、“我等你报警”等。
- **起诉**：用户表示让公司去起诉，而非自己去起诉公司。例如，“你起诉抓我吧”、“你去法院起诉吧”、“你起诉关我什么事”等。
- **法院**：用户表示让公司已经向法院申请诉执，并非自己去法院起诉公司。例如，“你不是已经申请法院执行了么”、“哪个法院”等。
- **曝光**：用户表示平台曝光自己的通讯录，并非是在社交平台上发表不当言论。例如，“你们都曝光我的通讯录了”、“你们都曝光我的征信了”。
- **抖音**：公司可能与抖音有流量业务或者投流，导致用户说的并非抖音发表不放言论。例如，“抖音上的那个广告么”、“抖音上的那个xx是么”。

## 3. 详细规则

以下内容是基于 rocketx 的规则引擎编写，针对一些关键词无法用正则达到较高准确率的情况，可以考虑优化 `instruction` 内容让大模型接管进行推理。

version: "0.1"
scenes:
  - intent: complaint_social
    description: 舆情风险
    instruction: |
      我们公司是一家金融借款平台，你是风险预警专员，能准确从对话内容中判断出用户所说内容是否具有舆情风险。
      ## 描述
      舆情风险的定义：用户提及去抖音等社交平台上发表不利于公司品牌的言论，类似行为还有去法院起诉公司、报警抓公司等。
      ## 示例
      ### 示例1
      USER: 我们就报警了，你们等着吧。
      ## 限制

      ## 上下文


    scene_id: COMPLAINT_003
    risk_level: 高
    enable: true
    role: user
    formula: "{r1} & (!{r2})"
    scene_rules:
      - rule_id: r1
        positive: true
        regexes:
          - reg: (我|我们).{0,3}(都|就|要|去|这边|马上|刚刚|已经|准备|该|给你|可以|直接|立刻){1,3}.{0,4}报警

          - reg: 给我(发短信|打电话).{0,6}(警察局|派出所)|我已经[到去](警察局|派出所)
          - reg: (曝光|去告).{0,3}(你|你们)
          - reg: 曝光.{0,6}(等着吧|你们等着)|(把|给|帮)你曝光
          - reg: (抖音|小红书|贴吧|平台上|网上|节目组|微博|电视台|电台|报社).{0,6}曝光

        positive: true
        regexes:

          - reg: 起诉.{0,4}离婚
          - reg: 你去法院|什么法院|中国法院网
          - reg: 曝光.{0,6}(隐私|通讯录|通讯记录)
          - reg: (隐私|通讯录|通讯记录).{0,6}曝光
