# 监管投诉

## 1. 业务背景

本文介绍一个催收业务下比较常见的高风险场景——监管投诉，具体表现为“用户提及去监管机构等进行投诉“行为，此类风险一般偏高，如用户真实去监管投诉的话，提前进行易诉处置，避免升级成重大投诉。
