# 钱塘动账

鹰眼是钱塘征信推出一款动账预警产品，它通过对接若干个支付机构，能及时获取客户银行卡的动账数据，并高频通知金融放款机构，相应地放款机构可以在获知通知后立即发起扣款，从而在多头用户的“抢钱大战”中赢得先机。目前该产品主要针对逾期用户的动账监控，目前在M1内的效果较好，而M2+回收效果一般。
