# 钱塘动账

鹰眼是钱塘征信推出一款动账预警产品，它通过对接若干个支付机构，能及时获取客户银行卡的动账数据，并高频通知金融放款机构，放款机构可以在接到通知后立即发起扣款，从而在多头用户的“抢钱大战”中赢得先机。

此外，钱塘介绍该产品主要针对是逾期用户的动账监控，目前在M1内的效果较好，M2+回收效果一般。某头部友商使用该产品后，3个月成功多扣款1000多万元。
