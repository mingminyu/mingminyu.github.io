# 前言

在大模型应用落地时，我们经常遇到 “复杂问题超神”、“简单问题翻车”、“运行不稳定”、“小问题容易滚雪球成大事故” 等问题，这些都是目前 Agent 迈向生产力的最大障碍，比较公认的解决方案就是 **驾驭工程**（Harness Engineering）。

就如字面上理解一样，驾驭工程就是如何通过指令驱动大模型按照预期的方式进行工作，但其背后的技术却不是那么简单易学，主要原因在于驾驭工程并不是标准化的技术解决方案，而是一套“用好 Agent”的工程经验总结。真正高价值的经验，一定只源于长期的工程实践总结，而不是简单地采用一个Agent负责编码，另一个Agent负责审核的方式，虽然这也算是以一种 Harness Engineering。

本套课程系统学习 Harnness Engineering 核心原理和实践流程，并从零搭建两套 Harness 系统，分别是 **Skill淬炼系统**和**Skill优化系统**，能够在多轮对话过程中，自动抓取高频任务并提炼成Skill，并且能够自动创建数据进行自我审核与优化迭代，目前这是工业级的 Harness 系统必备的核心能力之一。同时，最近的大火的 Hermes Agent 核心原理也会详细介绍。

通过横向对比，介绍三代AI交互方式的异同，帮助大家快速建立 Harness Engineering 这一概念的基础认知。
