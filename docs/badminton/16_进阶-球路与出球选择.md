## 1. 基础线路

### 1.1 直线球路

- 特点：速度快、风险低

### 1.2 斜线球路

- 特点：拉开宽度

### 1.3 对角球路

- 特点：调动对手

### 1.4 同线球路

- 特点：压迫退后

### 1.5 变线球路

- 特点：打乱节奏

## 2. 调动线路

### 2.1 前后球路

- 作用：控制距离

### 2.2 左右球路

- 作用：拉开空间

### 2.3 四方球路

- 作用：全面调动

## 3. 目的性线路

### 3.1 中路球路

- 作用：限制对手发力

### 3.2 空档球路

- 作用：提高得分效率

### 3.3 重复球路

- 作用：消耗对手体能

### 3.4 变化球路

- 作用：制造机会

## 4. 局面选择

### 4.1 过渡球路

- 策略：争取调整时间

### 4.2 主动球路

- 策略：掌控比赛节奏

### 4.3 被动球路

- 策略：稳住当前局面
