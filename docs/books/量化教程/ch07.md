# 第七章 实盘交易

有合适的量化策略后，最重要的就是去实盘跟踪，实盘的方法有两种，第一种是根据策略的买卖信号，手动跟踪。第二种是自动交易。

我的建议是用自动交易，手动跟踪很难跟上，时间长了节奏会乱掉，自动交易的好处我就不多说了，主打就是一个省心省力。不过我还是会介绍关于手动跟踪的方法，毕竟每个人的需求不一样，条条大路通罗马，教程的关键点在于把这些“路”都打通，让大家有得选择。

这一章，我会介绍手动跟踪和自动交易的方法：经过十年多的实践，推荐自动交易，支持的策略多，且简单容易上手，可以先开PT，目前国盛PT比较稳定。也可以开国金PT，有一定概率会被风控，如果国金PT不能用了，可以切换为QMT，如果都是开的国金，那么两个方案可以互相平替


| 实盘方式 | 具体实盘形式 | 需要的准备 | 支持券商 | 门槛 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 手动跟踪 | 聚宽创建实时模拟，通过微信通知手动操作 | 1.只需要开通聚宽实时模拟 | 无限制 | 无 | 简单 | 手动可能跟不上 |
| 自动交易-QMT | 聚宽创建实时模拟，把交易信号传递给券商QMT，通过QMT自动下单 | 1.需要开通聚宽实时模拟<br>2.需要开通券商QMT软件的权限 | 国金 | 国金要10万开权限 | 1.可以实时自动跟着聚宽模拟策略<br>2.只要聚宽支持的策略，都可以实现自动交易 | 流程略复杂，需要有耐心 |

## 1. 手动跟踪：微信通知(手动跟踪)

这篇主要教大家怎么通过微信接收聚宽的实时交易信号，然后手动跟踪。此方法的预计成本：

1. 最大花费999元一年
2. 最小花费0元

### 1.1 开通聚宽实时模拟

聚宽默认是延时模拟，延时模拟会延时一天交易，比如策略12月14日9点35分买进股票A，但延时模拟会延时到15日的凌晨3点发出交易信号，并且延时模拟不支持微信通知。

所以如果想要微信通知，就要先开通实时模拟权限。

开通实时模拟有两种方式：

1. 购买聚宽的蓝V会员，价格是999元一年，会员会送三个实时模拟的坑位。
2. 通过聚宽的社区的积分，兑换实时模拟坑位。兑换的流程可以看这个帖子：[用积分兑换实时模拟的流程](https://t.zsxq.com/15qQPMp7A)

积分不要钱，但需每天去聚宽签到、看帖子、留言。

开通完实时模拟后，可以在[聚宽模拟交易列表页](https://www.joinquant.com/algorithm/trade/list?process=1)，看到模拟交易的状态，如果显示是“实时进行中”，那就说明实时模拟设置成功了

![](images/7-01.png)

### 1.2 开通微信通知

只要开通了实时模拟，点击下面这个按钮，开通微信通知开关就可以了，只要按钮的状态显示“ON”，就代表这个策略已经开启微信通知。

## 2. 自动交易Ptrade：聚宽实时模拟，通过ptrade自动下单

本章主要教大家实现聚宽实时模拟，然后通过 ptrade 自动下单。**好处就是： 1.可以实时自动跟单聚宽模拟策略。2.只要聚宽支持的策略，都可以实现自动交易**。

这个方案设置完后，你们就可以把聚宽实时模拟当成以前的一创聚宽了，第一次设置完后，之后都可以忽略 ptrade 的存在，还实现了邮件提醒，ptrade下单成功，或者是报错都会通过邮件告知，不用经常登 ptrade 去查看，可以把ptrade理解成一个隐形的下单工具。

参考资料：聚宽---蒋老师

此方法的预计成本：

1. 最大花费999元一年
2. 最小花费0元

### 2.1 证券开户

支持两种证券，分别是国金和国盛，但目前国金PT会封外网，开了也可能用不了，所以只支持开国盛。

国金证券：ptrade权限的开通门槛10万，手续费是万1。可以联系客户经理直接开户。国盛证券：nb823412

还是要强调一下，目前只有国金/国盛才支持该方案。

### 2.2 开通ptrade权限

开完户后，只要入金的金额达到了要求，就可以让客户经理帮你们开通ptrade的权限了，监管目前对量化有很多要求，所以开权限的时候客户经理会让你们填很多材料，按照要求填就可以了，这个有问题可以找客户经理。

开完ptrade权限后，客户经理会告诉你们怎么下载ptrade软件。

### 2.3 申请mysql数据库

先说明一下，mysql数据库的作用是转发下单消息，目的是用它把聚宽的信号转移到Ptrade上，Ptrade一旦下单成功，就会从数据库删除这条交易信息。

申请mysql数据库的方法：

微信联系doudougua2，我会给你一个星球专属的数据库账号密码和连接地址，但这个数据库账号到期时间同星球到期时间，星球到期不续费就没法用了，续费才可以继续用。这个的好处是数据库很稳定，不容易出问题。

### 2.4 在ptrade上运行接收聚宽信号的自动交易代码

登录ptrade软件，先点击左侧【量化】按钮，再点击顶部的【回测】按钮，就可以看到量化的界面了。

### 3.7 开通聚宽实时模拟

聚宽默认是延时模拟，延时模拟会延时一天交易，比如策略12月14日9点35分买进股票A，但延时模拟会延时到15日的凌晨3点发出交易信号，并且延时模拟不支持微信通知。

所以如果想要微信通知，就要先开通实时模拟权限。

开通实时模拟有两种方式：

1. 购买聚宽的蓝V会员，价格是999元一年，会员会送三个实时模拟的坑位。
2. 通过聚宽的社区的积分，兑换实时模拟坑位。兑换的流程可以看这个帖子：[用积分兑换实时模拟的流程](https://t.zsxq.com/15qQPMp7A)

积分不要钱，但需每天去聚宽签到、看帖子、留言。

开通完实时模拟后，可以在[聚宽模拟交易列表页](https://www.joinquant.com/algorithm/trade/list?process=1)，看到模拟交易的状态，如果显示是“实时进行中”，那就说明实时模拟设置成功了。

### 3.8 将修改后的策略源码在聚宽上进行实时模拟

**注意**：在ptrade未设置完成前，千万不要先在聚宽运行mysql版本的实时模拟，一定要ptrade先运行，再去运行聚宽实时模拟，或者聚宽实时模拟（要在24点前）和PT同一天运行。

这步我就不多讲了，就是把我们修改后的策略源码在聚宽上进行实时模拟。这里有一点要注意，你模拟填写的金额是多少，那么对应ptrade下单的金额就会是多少。举个例子，你模拟了高股息小市值策略，起始资金是10万，买10只，那么对应发给ptrade就会每只买1万。也就是说ptrade买多少股票，全看模拟设置的金额是多少。

实盘时，一定要确保券商账户的资金比聚宽模拟策略设置的资金多5%左右，举个例子，你聚宽模拟设置的是10万，那么国盛券商账户最好放10.5万，不然可能会报资金不足。

### 4.4 高股息小市值-增加了1底和4月底择时-增加了止损（自动交易）


高股息小市值也改造好了，主要加了几个逻辑：

1. 1月19日-1月31日，4月19日-4月31日空仓 。
1. 增加止损逻辑：每日早上10点检查好，只要持仓股票跌幅大于-10%，就卖出。
1. 尾盘14:50，判断是否异常放量，当日异常放量就卖出。单日放量的定义：当日成交量超过过去120天中最大量能的90%。
1. 增加了筛选条件：过去四个季度营收必须大于5亿，eps必须大于0。
1. 如果因为连续不涨停卖出，则次日会把仓位重新买满。如果因为止损而卖出，次日不会重新买满，而是等到下一个调仓日再买满。
1. 调仓日期，我发现不一定要每月第一个交易日调仓，设定为每日第3/4/5个交易日也不错。还有就是也可以设定为周调仓，周调仓设定很简单，把`run_monthly`，换成 `run_weekly` 就好了。如果设定为周调仓，且每周第二个交易日调仓，我发现效果特别好，不知道是否有拟合的因素。新代码里，我设定的还是月调仓，每月的第5个交易日调仓，有兴趣的可以自己改改试试，不一定要按照原代码来。

修改后，收益增强挺明显的，原策略2016年---2024年，收益是864%，最大回撤-40%。修改后是3259%，最大回撤-24.8%。

我还是那个观点，我做这些改造和优化，增加止损，只要是给低风险偏好的圈友一个选择，不一定说必须要去择时，毕竟择时也可能会付出踏空的代价，但择时和止损，确实可以降低一定的风险，这是一个取舍的问题。

另外，这次加上了应对新规的财务筛选，营收和eps都做了最低筛选，财务安全性应该还是比较高的。

def get_dividend_ratio_filter_list(context, stock_list, sort, p1, p2):
    time1 = context.previous_date
    time0 = time1 - datetime.timedelta(days=365)
    #获取分红数据，由于finance.run_query最多返回4000行，以防未来数据超限，最好把stock_list拆分后查询再组合
    interval = 1000 #某只股票可能一年内多次分红，导致其所占行数大于1，所以interval不要取满4000
    list_len = len(stock_list)
    #截取不超过interval的列表并查询
    q = query(finance.STK_XR_XD.code, finance.STK_XR_XD.a_registration_date, finance.STK_XR_XD.bonus_amount_rmb
    ).filter(
        finance.STK_XR_XD.a_registration_date >= time0,
        finance.STK_XR_XD.a_registration_date <= time1,
        finance.STK_XR_XD.code.in_(stock_list[:min(list_len, interval)]))
    df = finance.run_query(q)
    #对interval的部分分别查询并拼接
    if list_len > interval:
        df_num = list_len // interval
        for i in range(df_num):
            q = query(finance.STK_XR_XD.code, finance.STK_XR_XD.a_registration_date, finance.STK_XR_XD.bonus_amount_rmb
            ).filter(
                finance.STK_XR_XD.a_registration_date >= time0,
                finance.STK_XR_XD.a_registration_date <= time1,
                finance.STK_XR_XD.code.in_(stock_list[interval*(i+1):min(list_len,interval*(i+2))]))
            temp_df = finance.run_query(q)
            df = df.append(temp_df)
    dividend = df.fillna(0)
    #dividend = dividend.set_index('code')
    #print(dividend)
    dividend = dividend.groupby('code').sum()
   # print(dividend)
    temp_list = list(dividend.index) #query查询不到无分红信息的股票，所以temp_list长度会小于stock_list
    #获取市值相关数据
    q = query(valuation.code,valuation.market_cap).filter(valuation.code.in_(temp_list))
    cap = get_fundamentals(q, date=time1)
    cap = cap.set_index('code')
    #计算股息率
    DR = pd.concat([dividend, cap] ,axis=1)
    DR['dividend_ratio'] = (DR['bonus_amount_rmb']/10000) / DR['market_cap']
    #排序并筛选
    DR = DR.sort_values(by=['dividend_ratio'], ascending=sort)
    print(len(DR))
    final_list = list(DR.index)[int(p1*len(DR)):int(p2*len(DR))]
    return final_list

### 4.7 中小板小市值-国九升级版-1月4月空仓-调仓时间随机(自动交易)

中小板小市值策略，依然会贯彻大道至简的原则，不会增加复杂的止损止盈和择时逻辑，只会加必要的筛选逻辑。

加上以上条件后，2019年1月1日----2024年12月25日，收益是2884%，年化80%，最大回撤-30%，总体还是不错的。

详细说一下这个策略优化后的逻辑：

- **选股逻辑**：选择股票代码开头1位是“0”开头，净利润大于0，归母净利润大于0，扣非净利润大于0，上个季度营收大于1亿。
- **排序逻辑**：按照市值从小到大排序，买入市值最小的5只票。
- **买卖逻辑**：按照市值轮动，每天检查一次，一旦市值掉出最小的前7，就卖出，并重新买入当前排名前5的票。
- **择时逻辑**：每年1月1日-1月31日空仓，4月1日到4月30日空仓。
- **资金分配**：动态等权重买入，比如用10万跑这个策略，当前持仓1只（4万元），还剩6万，且还有4只可以买，那么剩下4只就是6/4=1.5万元每只。

### 4.10 动态持仓中小板小市值国九条版（自动交易）

圈友@飞扬 提供了一个动态持仓中小板小市值策略，看起来还不错，2024年收益136%，可以研究研究。

这个策略比原版中小板小市值强，加了动态持仓逻辑，行情好的时候集中持仓，行情差分散持仓。另外，还加了部分国九条的条件。不过这个策略因为有择时和止损逻辑，容易左右打脸，实盘体验不一定好。

我看了下，大致是以下逻辑：

- **股票池**：中小板成分股
- **选股逻辑**：

    - 总市值在10-100亿之间
    - 上个季度净利润净利润大于0
    - 上个季度归母净利润净利润大于0
    - 最近一个季度营收大于1亿
    - 过滤近一年审计建议无法出具或者为负面建议的
    - 股价不高于50块

- **排序逻辑**：按照总市值，从小到大排序
- **择时逻辑**：1月和4月时，计算国证2000指是否止跌，止跌则买入，不止跌则空仓。
- **止盈止损逻辑**：持仓个股赚100%，或者持仓个股亏损-9%，或者中小板指数单日跌-5%
- **持股数量逻辑**：默认持有4只，但会根据中小板综指（399101）的diff来判断持有多少只：

    - diff 大于等于500时，持有3只；
    - diff 在200和500之间时，持有3只；
    - diff 在-200和200之间时，持有4只；
    - diff 在-500和-200之间时，持有5只；
    - 其他情况，持有6只。

    diff的计算方法是用指数最新收盘价-过去10个交易日的均价

- **调仓频次**：每周第三个交易日的9点31进行调仓，每日10点止盈止损，每日14:20卖出连续不涨停的票。

ps:如果模拟，首周运行的第一天算是以第一个交易日。

这个策略具体实盘表现怎么样我没研究过，提供的圈友认为是挺不错的，感兴趣可以自己研究一下。

### 4.12 低资产回报小市值策略（自动交易）

低资产回报小市值。底层逻辑：固定资产越少，资产回报率越低的小市值公司，躺平的概率越低，寻求转型或者并购的概率越高，能产生更大的潜在预期差。

策略录入时间：2026-04-30。
策略更新：修复了获取全市场股票的问题，2026-05-07。
提醒：不要分享到社区，用的人越多，拥挤度越高，没必要这么做。

详细逻辑如下：

- **股票池**：排除科创北交外，所有A股股票。
- **选股逻辑**：先选出全市场资产回报率最低的10%的股票，然后再从这些股票里再选出固定资产最低的25%股票。
- **排序逻辑**：按照市值从小到大排序，取前10个股票。
- **调仓逻辑**：策略用轮动的方式进行买卖，每周轮动一次，在前12名的股票会继续持有，掉出前12名股票就会卖掉。轮动时间为每周的第1个交易日。
- **择时逻辑**：每年的1月和4月的20号之后空仓，其他时间皆满仓。

### 4.13 纯高股息基本面策略(自动交易)

纯高股息策略，没有任何小市值因子，纯纯的高股息+基本面筛选的策略。按照持股数不同，最近12年的年化不同，持有3只，年化可以接近50%，最大回撤-28%。持有5只，年化42%，最大回撤-28%。持有8只，年化31%，最大回撤-28%。。

![](images/7-48.png)

这个策略其实很简单，是在高股息小市值的基础上演变的，去掉了小市值排序改为最近3年股息率排序，还加了一些基本面的筛选因子。

具体逻辑：

1. 筛选最近三年股息率排名前10%的票。
2. PEG要在0.1-2之间。PEG太低是不合理的，比如PE是10，但业绩增速达到了200%，PEG达到0.05，这种要么是周期股，要么业绩有异常。PEG太高也不行，比如PE是10，但业绩增速只有2%，PEG达到5，这种增速太低了。相对来说，限制在0.1-2之间，就比较合适。
3. 营收增速同比大于3%，净利润增速同比大于8%，季度ROE大于4.5%，保证有一定的增长性。
4. 筛选完成后，按照股息率排行，买股息率最高的那几只票。
5. 一周调仓一次，每周一调仓。
6. 昨日涨幅大于8%，就暂时卖出。

大致就是这些，挺简单的，选出来的票主要是几百亿市值的中大盘股，小盘很少会被选中。这个策略从道理上讲，基本是靠谱的，高股息，合理的PEG，有一定的业绩增速，这种票确实挑不出毛病了。

风格的话，不算严格意义上的大票风格，小中大，都有可能会选上，中大盘选的会比较多，举个例子，最近6月份持有的5支票分别是4400亿市值的美的集团、86亿的陕天然气、462亿的海澜之家、33亿的宁波精达、300亿的养元饮品。

对了，这个策略我默认持有的事5只，因为8只太多了，有时候甚至可能都选不满，3只太少了，风险相对比较大，5只就恰恰好，不多也不少。PS：激进点的话，或者资金不多，选择3只比较合适。策略默认是5只。

### 4.14 大类资产再平衡（自动交易）

相比于绝对收益策略，大类资产再平衡更关注风险，多低相关资产对冲最大的优势并不是产生绝对收益，而是不同风格产生对冲，降低回撤。

多风格配置的核心一定是低相关性的核心大类资产，最典型的就是纳指、黄金、A股科技成长，A股小市值。

- **纳指（纳指ETF）**，是美国最优质的科技资产，降息周期+美国复苏+产业革命，纳斯达克都会起飞。
- **黄金（黄金ETF）**， 是优质避险资产，在全球风险剧增时，黄金可能走出独立行情。
- **A股科技成长（创业板ETF）**： 属于抽风资产，在特定环境下，弹性巨大，涨幅可以超过纳斯达克。
- **A股小市值**：熊市扛把子，市场越熊，小市值可能走得越好。

就用最简单的方案去做组合，每一种风格固定仓位权重，比如黄金20%，纳指20%，创业板20%，小市值40%。每个月再平衡一次，全年满仓，不择时。

这个策略思路非常简单，大道至简，逻辑越简单，鲁棒性就越强。

PS：策略中的小市值，用的是全市场选股，过滤ST和退市，过滤北交所和科创板，只取市值最小的5只票，掉出第7卖出，每周轮动一次。

这几种资产的权重，可以在策略里设置，小市值权重=100%-ETF相加的权重，比如你黄金20%，纳指20%，创业板20%，那么小市值就是40%。

不过，说实话，我心中最佳配比是黄金20%，纳指30%，创业板10%，小市值40%。我不喜欢创业板，创业板我认为不是一个非常好的资产，降低它的比率，可以有效降低回撤和波动率。

为了应对ETF停牌的事件，策略的交易时间改为10点40之后。
