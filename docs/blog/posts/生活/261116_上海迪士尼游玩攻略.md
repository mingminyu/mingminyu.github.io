# 上海迪士尼游玩攻略

!!! warning "出行前必查"

    票价按日期浮动、运营时间与演出场次按客流调整、恶劣天气可能取消烟花。当天以「上海迪士尼度假区」官方 App 的运营日历与实时等候时间为准。

**游玩路线**：

- **上午**：入园 → 疯狂动物城 → 七个小矮人矿山车 → 加勒比海盗 → 飞越地平线。
- **下午**：雷鸣山漂流 → 喷气背包飞行器 → 米奇童话专列

!!! warning "年龄的硬规则只有两条"

    官方不设最低年龄门槛，实际以身高 + 健康状况判定：不满 16 周岁须由 16 周岁及以上游客陪同**入园**；不满 7 周岁须由 16 周岁及以上游客陪同**乘坐项目**。「儿童及以上」表示官方适合年龄不含学龄前，「全年龄」含学龄前。现场严格量身高，==差 1 cm 也玩不了==。

## 4. 食物和行李

**可以自带食物**，例如密封零食、面包饼干、完整水果、坚果果干。 但不可携带需加热、再加热、加工、冷藏或保温的食品（泡面、自热锅）。

!!! warning "无法携带的行李"

    超过 56×36×23 cm 的箱包、任何带轮行李、折叠椅凳、自拍杆、三脚架均不可携带，自拍杆、折叠凳、大行李箱是最高频被拦的三样。
