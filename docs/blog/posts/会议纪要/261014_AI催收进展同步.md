# AI催收周会：M1话术运营+M2人机协同

## 1. M1话术运营

在下一个阶段需要汇报以下事项的进展：

1. 轮次标签的准确率验证结果
2. 回溯9月打标数据
3. 分析轮节点漏斗的数据分布，输出一份分析报告，包含流程和节点话术的优化建议
4. 固定一版意图和话术标签，推动线上实时落轮次级别的意图和话术标签
5. 将设计的话术体系在 M1 自研 AI 上应用

## 2. M2人机协同

以 AI 人机协同里程碑方式进行汇报，从 26年10月开始到 27年12月（建议27年按照 Q 拆分时间段）各节点的功能规划、上线实现、实现效果。

## 3. 全指标体系

1. 分案：金额段、逾期标签等维度分布表现
2. 链路指标：接通率
3. 结果指标：回收率，以及叠加金额段、逾期天数等维度回收率
4. 过程指标：对话轮次、通话时长、节点漏斗
