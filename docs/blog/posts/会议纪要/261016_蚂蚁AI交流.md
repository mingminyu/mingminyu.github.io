# 蚂蚁AI交流

本次会议明确了TTS出厂级专家模型的核心目标与ASR在电话场景下的优化方向，确立了TTS需强化专业感与细粒度控制，并针对8k信道、方言噪声等痛点推进DDT SR专项优化。
小结

1. TTS核心目标与能力规划

确立出厂级专家目标：首要目标是打造“出厂级专家”模型，使客户在各业务场景中可直接调用，无需二次适配。
强化专业感与场景属性：模型需具备强专业感并匹配特定业务场景属性。

营销场景：要求语气更热情、更具感染力。
催收场景：要求语气相对严肃、正式。

<!-- more -->

细化语言控制能力：需在沟通全过程中提供细粒度的控制手段，以辅助业务目标的达成。
补足Zero Shot能力：针对外部客户需求暴露出的不足，后续需重点补齐Zero Shot相关技术能力。

2. ASR电话场景痛点与优化方向

明确电话场景识别痛点：实际电话应用中存在多项微小但关键的识别障碍。

环境与信号问题：涵盖方言、背景噪声、近远场差异以及基准8k信道与通用语音识别的Gap。
业务专有名词：特定业务领域的专有名词识别率有待提升。


推进DDT SR专项优化：针对上述痛点，启动DDT SR项目，重点对8k信道进行深度优化。


本次会议围绕AI外呼产品的效果评估与优化展开，探讨了线上真实对话的评估维度、人工与批量对比机制，并介绍了基于智能体的自动评测与调优能力。
小结
1. AI外呼产品评估维度

多维线下评估指标：需综合考量时延、打断自然度、业务专业性、完整性及准确性等多个核心指标。
线上真实效果验证：最终需投放至线上观察实际效果，并与人工坐席的真实对话表现进行PK，分析ROI及各厂商AI外呼产品的效果差异。

2. 效果评估与优劣势分析

人工检查依赖：测试样例回复是否满足预期，目前主要依赖于人工进行逐项检查。
回收数据对比机制：上线测试后需对回收数据进行优劣对比，剔除外在因素后深入分析AI能力的具体欠缺点。
使用方工具化应用：作为使用方需借助该评估工具来定位问题，从而针对性地优化后续的AI催收能力。

3. 智能体自动评测与调优

开发智能体评测功能：近期正在研发类似评测Agent和调优Agent的专门智能体。
自动化对话评估：针对线上实际发生的对话，由智能体从专业角度进行评估打分。
基于分数的持续调优：在获取专业评估分数后，智能体能够基于此结果继续执行优化操作。
