# 学习

## 1. 学习方法

!!! quote "学习的第一性原理"

    - 学习的第一性原理是**自学**，而不是补课
    - 刷题的第一性原理是**归纳**，而不是数量
    - 错题的第一性原理是**复盘**，而不是抄写
    - 记忆的第一性原理是**理解**，而不是重复
    - 考试的第一性原理是**基础**，而不是技巧
    - 知识的第一性原理是**体系**，而不是碎片
    - 过程的第一性原理是**专注**，而不是耗时间

!!! quote "学习的10个层次"

    - 翻过书叫**接触**
    - 看过书叫**浏览**
    - 能复述叫**记忆**
    - 能用自己语言讲出来叫**理解**
    - 能把知识点串联起来叫**搭建体系**
    - 能举一反三叫**贯通**
    - 能发现知识点中异同叫**辨析**
    - 能从做题中总结规律叫**提炼**
    - 能融汇多领域知识，催生新知识叫**创新**
    - 能用知识改变自己的行为叫**内化**
