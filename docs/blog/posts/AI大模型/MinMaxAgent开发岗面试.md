# MiniMax Agent 开发岗面试

## 1. Agent执行链路

1. 用户输入需求之后，系统怎么识别意图，怎么拆任务，多个步骤谁先谁后，什么时候调用模型，什么时候调用工具，不同任务怎么选择模型？
1. Skill是怎么设计的？
1. 长短期记忆怎么区分？什么信息进入长期记忆？怎么存？怎么召回？数据膨胀怎么办？Memory 越存越多怎么解决？
1. 项目上下文窗口是多少？实际会用到多少？什么时候触发压缩？怎么压？效果怎么评估阈值怎么定？压缩以后重要信息丢失怎么办？
1. 不同业务怎么选模型？如果让 Agent 写 1000 行代码大概消耗多少 Token？百万 Token 怎么计费？一次任务成本消耗多少？
1. 调用 Tool Calling 失败怎么办？线上怎么兜底？

## 2. 从0到1搭建Agent 

1. 设计一个企业级 Agent，系统怎么拆？用户请求进来怎么识别任务？怎么判断是简单任务还是复杂任务？复杂任务怎么拆成子任务？又怎么生成执行计划？执行以后怎么判断当前Step是成功还是失败？工具超时了怎么办？什么时候 retry？什么时候重新规划？任务执行一半，服务挂了怎么去重新恢复？
1. MiniMax Code：如果让 Agent 理解一个大型仓库代码，不可能把几十万行的代码全部塞进上下文，那怎么结合向量检索、关键词搜索、AST分析和调用链分析，构建当前任务需要的 Code Context 呢？
1. 工具系统怎么设计？工具怎么注册？Schema 怎么定义？哪些工具只能读？哪些工具只能写？高风险操作怎么做权限管控？
1. DSH Open Code、Claude Code、CodeX 这些开源 Harness 应用的对比和使用？

## 3. Agent开发职业发展

1. 为什么选择 Agent ？未来方向怎么看？定期有没有关注 AI 大事？
1. 有没有用过最新的 Opus5.5，GPT6.1？
1. 对全天候Agent有什么看法？
1. AI时代怎么学习才不会被淘汰?
1. 自己和其他候选人的差异是什么？能给公司创造什么价值？
