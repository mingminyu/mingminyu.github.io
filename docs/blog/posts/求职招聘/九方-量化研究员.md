# 量化研究员

我们是九方智投新孵化的AI量化投资团队，探索机器学习、深度学习、大模型及智能体技术在量化投资中的应用。

我们希望寻找兼具研究深度、技术广度和实盘经验的伙伴，承担核心研究课题，推动研究成果从数据、模型和策略验证走向实盘应用，并参与团队早期研究体系与技术平台建设。

## 1. 岗位职责

1. 独立开展策略研究: 围绕市场提出研究假设，完成数据分析、因子挖掘、模型构建、回测验证及策略迭代。
2. 推进AI模型应用: 运用机器学习、深度学习开展收益预测、金融时间序列建模和多源数据融合，探索大模型、强化学习等方法的适用场景。
3. 负责实盘研究与迭代: 参与策略上线、运行监控、绩效归因和风险分析，定位信号衰减、交易偏差及回撤来源，持续优化实盘表现。
4. 开展组合与交易研究: 结合风险暴露、换手率、流动性、交易成本及容量约束，优化信号组合、仓位配置与交易执行。
5. 建设AI研究工具: 开发或推动落地面向投资研究的智能体，将数据检索、信息提取、代码执行、实验管理和结果分析连接为可评估的工作流程。
6. 完善研究体系: 参与数据规范、回测框架、模型评估和实验管理建设，提升研究效率及结果可靠性。
7. 推动团队协作: 与研究、工程及业务同事协作，开展代码与研究评审，指导初级研究员和实习生。

## 2. 任职要求

1. 2-5年量化研究或量化投资相关工作经验，研究生及以上学历，计算机、数学、统计、物理、人工智能、金融工程等相关专业。
2. 具备真实策略实盘经验，曾承担策略研发、上线或持续迭代中的核心工作，能够清晰说明本人贡献、实盘周期、收益与风险来源，以及回测与实盘差异的处理过程。
3. 具备相关研究或交易经验，至少在其中一个市场具备深入的策略研究与实盘积累；理解不同市场在交易机制、数据口径、流动性、卖空约束和交易成本等方面的差异。
4. 具备完整的量化研究能力，能够独立完成数据处理、因子评价、预测建模、组合构建、回测分析和实盘归因，理解各环节之间的影响。
5. 具备扎实的数理与统计基础，熟悉统计推断、时间序列分析及优化方法，能够识别数据泄漏、过拟合、多重检验和样本选择偏差。
6. 具备较全面的AI技术能力，熟悉机器学习与深度学习，在因子挖掘、时间序列建模、大模型应用、强化学习中至少一个方向有深入实践，并能理解和应用其他相关方法。
7. 具备较强的工程实现能力，熟练使用Python、SQL、PyTorch及常用数据分析工具，能够编写可维护、可复现的研究代码，完成复杂问题的调试与性能优化。
8. 能够阅读英文论文及金融材料，独立跟踪前沿研究，基于对照实验和实际投资效果判断方法价值。
9. 具备研究判断力、责任心和协作能力，能够在新团队中主动定义问题、推动落地并对结果负责。

## 3. 优先条件

1. 有量化私募核心研究经历，独立负责过策略或重要研究模块，并持续参与实盘迭代。
2. 有跨市场研究及实盘经验，能够分析策略在不同市场中的可迁移性与失效原因。
3. 有AI智能体实际落地经验，熟悉工具调用、任务规划、上下文管理、代码执行及效果评估，能够展示对研究效率或质量的具体改善。
4. 有大模型微调、金融文本建模、RAG、时序预训练模型或多模态数据研究经验。
5. 有强化学习在组合优化、仓位管理或交易执行中的研究与应用经验。
6. 有研究平台、因子平台、回测系统或实盘监控体系建设经验。
7. 有C++、分布式计算、GPU训练优化或大规模数据处理经验。
8. 有高质量论文、开源贡献或带领研究项目、培养研究人员的经历。
