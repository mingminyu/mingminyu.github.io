## 2. 核心句型

**重点：询问物品在哪里，Where 引导的特殊疑问句练习**

|      | 单数                                               | 复数                                                     |
| ---- | ------------------------------------------------ | ------------------------------------------------------ |
| 问句   | ==Where's== + 单数物品? ……在哪里？                       | ==Where are== + 复数物品? ……在哪里？                           |
| 答句   | **It's in the + 房间.** 在……房间里。                    | **They're in the + 房间.** 在……房间里。                       |
| E.g. | Where's my teddy bear?<br />It's in the bedroom. | Where are my teddy bears?<br />They're in the bedroom. |

!!! tip "语法小提示"

    **Where's = Where is**；**Where are 不能缩写**。
