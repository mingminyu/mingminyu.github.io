## 2. Key grammar: don’t like & doesn’t like(不喜欢)

| 词汇/句型 | don't like | doesn't like |
| --- | --- | --- |
| 肯定句 | I /You /We /They + like | He /She /It + likes |
| 否定句 | I /You /We /They + don't like | He /She /It + doesn't like |
| | don't have | doesn't have |
| 肯定句 | I /You /We /They + have | He /She /It + has |
| 否定句 | I /You /We /They + don't have | He /She /It + doesn't have |
| **核心规律** | I /You /We /They + don't + V 原 | He /She /It + doesn't + V 三单 |

## 3. 核心句型

**I don’t like + 名词复数形式，表示一类**。

- I don’t like bananas. 我喜欢香蕉。
- I don’t like grapes. 我喜欢草莓。

**I don’t like+ 不可数名词**

- I don’t like coffee.    我喜欢咖啡。
- I don’t like apple juice.   我喜欢苹果汁。
